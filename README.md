# 零售销售与商品结构分析

[在线演示 · 打开分析看板](https://retail-mix-analysis-9nqqx2u6mathhodbfunom3.streamlit.app/)

基于 **UCI Online Retail II** 百万条交易明细，分析销售增长、商品贡献与客户复购。使用 Python 计算指标、SQLite 复核结果，并通过 Streamlit 展示。

项目围绕三个问题展开：销售额增长来自订单量还是客单价？哪些商品贡献了增长？客户是否持续回购？

## 主要发现

以下结果使用全部地区数据；2011 年同比只比较 1—11 月的完整月份。

| 分析主题 | 结果 |
| --- | --- |
| 销售增长 | 2011 年 1—11 月正向销售额同比约 **+1.8%**。按先订单量、后客单价的顺序拆解，订单量贡献 **−£523,446**，客单价贡献 **+£686,238** |
| 月度分布 | 2010、2011 年 11 月均为当年销售高点，正向销售额分别约 **£1.47M、£1.51M** |
| 商品贡献 | 排除服务与调整类记录后，前 20 个商品贡献约 **11.5%** 的商品销售额 |
| 客户复购 | **5,881** 位可识别客户中，约 **72.4%** 在整个观察窗口内有至少两张销售发票 |

## 交互分析

- **销售增长**：月度销售趋势、订单量与客单价贡献拆解、年度月度对比。
- **商品结构**：商品排行、累计销售贡献、可比月份商品增减。
- **客户复购**：购买频次、按首次观察购买月份划分的 cohort 回购热力图。
- **数据与复现**：退货金额占比、数据质量检查、结果 CSV 下载和 SQL 查询。

日期和地区在页面顶部筛选，图表随筛选结果更新。

## 快速开始

需要 **Python 3.10+**。在项目根目录执行：

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

打开终端显示的浏览器地址。数据已随项目提供，无需配置数据库或额外下载。

在 PyCharm 中可创建 Python 运行配置：目标选择模块 `streamlit`，参数为 `run app.py`，工作目录选择项目根目录。

### 复现分析

```bash
python -m src.reproduce --verify-sql
```

该命令生成分析报告与 CSV，并用 SQLite 核对 Python 的月度指标、商品贡献和已观察 cohort 结果。生成文件位于 `outputs/`，不纳入版本管理。

### 运行测试

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

测试覆盖退货识别、缺失客户、服务类商品、完整月份、同比拆解、cohort 截尾、空结果和 SQL/Python 一致性。

## 数据与口径

数据来源：[UCI Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii)。项目内的 `online_retail_ii.csv.gz` 为工作簿转换摘要，包含 **1,067,366 条商品行**，覆盖 **2009-12-01 至 2011-12-09**，金额单位为英镑。复现流程从这份摘要开始。

| 指标 | 定义 |
| --- | --- |
| 正向销售额 | 非退货商品行的数量 × 单价，包含服务与调整类记录 |
| 净销售额 | 正向销售额 − 期间退货金额 |
| 销售订单 | 不同非退货发票号数量 |
| 客单价 | 正向销售额 ÷ 销售订单数 |
| 期间复购占比 | 期间有至少两张销售发票的客户 ÷ 期间可识别客户 |
| cohort 回购比例 | 同一首购客群在后续月份购买的人数 ÷ 该客群人数 |

- 发票号以 `C` 开头、数量为负或已有退货标记的行，按退货/取消处理，金额记负数。
- 商品按编码合并；邮费、手续费、折扣及人工调整等记录保留在总额中，从商品分析排除。分类规则见 [分析模块](src/analysis.py)。
- 缺失客户编号的行保留在销售统计中，不参与客户分析。
- 完整月依据观察窗口及所选日期判断。2011 年 12 月仅覆盖到 9 日，不纳入同比和月度留存。
- cohort 使用筛选起点以前的地区内购买历史；未来未观察到的月份留空，已观察但未购买的月份为 0%。

增长拆解是金额恒等式，不能解释为因果归因；客单价变化也不等于单品价格变化。首购仅指数据窗口内首次观察购买，期间退货金额比不是订单最终退货率。数据不含成本、流量和实验结果，不能据此计算利润或验证运营措施效果。

## 项目结构

```text
.
├── app.py                     # Streamlit 展示入口
├── src/
│   ├── analysis.py            # 数据处理与分析
│   └── reproduce.py           # 报告生成与 SQL 核对
├── sql/                       # 月度经营、商品贡献、cohort 查询
├── tests/                     # 指标与边界测试
├── .streamlit/config.toml     # 暖色主题
├── online_retail_ii.csv.gz    # 公开交易数据摘要
├── requirements.txt          # 运行依赖
└── requirements-dev.txt      # 测试依赖
```
